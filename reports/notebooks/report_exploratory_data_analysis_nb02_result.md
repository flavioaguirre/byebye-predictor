# Exploratory Data Analysis (EDA) Results & Insights

---

## Executive Summary

In this notebook, we performed a comprehensive Exploratory Data Analysis (EDA) on the Telco Customer Churn dataset, leveraging a robust suite of custom EDA utilities. Our approach was modular, reproducible, and scalable, ensuring that all findings are well-documented and all visualizations are saved for future reference. This analysis provides a solid foundation for subsequent data preprocessing, feature engineering, and advanced modeling.

---

## 1. Data Loading & Configuration

We began by importing the necessary libraries and configuring the output directory and visual style for all generated plots. The Telco Customer Churn dataset was loaded from a versioned snapshot, ensuring full reproducibility and consistency across the pipeline.

---

## 2. Data Structure & Integrity

**Data Overview:**
- Using `dataframe_overview`, we summarized the dataset, inspecting the number of rows, columns, data types, unique values, and missing data.
- **Data Types:**
  With `data_types_overview`, we categorized features into categorical, numerical, binary, and continuous columns. This step is crucial for guiding subsequent analyses and modeling strategies.

---

## 3. Data Quality Assessment

**Missing Values:**
- We visualized and quantified missing values using `plot_missing_values`. This allowed us to quickly identify columns requiring imputation or special handling.
**Outlier Detection:**
  Outliers in continuous numerical features were detected using the IQR method. This helps prevent skewed model training and highlights potential data entry issues.

---

## 4. Feature Distributions & Relationships

- **Correlation Analysis:**
The correlation matrix, generated by `plot_correlation_matrix`, revealed relationships between numerical features, informing feature selection and engineering.
- **Target Variable Distribution:**
The distribution of the target variable (`Churn`) was visualized, confirming class imbalance and guiding our choice of evaluation metrics for modeling.
- **Numerical Features by Target:**
We explored how continuous features vary by churn status, uncovering patterns that may be predictive.
- **Categorical Feature Distributions:**
The distribution of categorical features was visualized, aiding in the identification of dominant categories and potential encoding strategies.
- **Numerical Feature Distributions:**
All numerical features were profiled for their distribution, skewness, and kurtosis, providing insight into normalization needs and model assumptions.

---

## 5. Statistical Profiling

- **Normality Tests:**
Using D'Agostino and Pearson's test, we assessed the normality of numerical features, informing our choice of statistical methods and transformations.
- **Skewness & Kurtosis:**
These metrics were computed for all numerical features, highlighting variables that may require transformation to improve model performance.
